# QA CHECKLIST — Driving School Platform

Cập nhật: 2026-05-26

## Unit / integration tests

```bash
npm install
cd server && npm install && cd ..
npm run build:sw-manifest
npm run test:client
npm run test:server
npm test
```

| Lệnh | Phạm vi |
|------|---------|
| `npm run test:client` | Jest client (textUtils, historyUtils, pipelineUtils, resultsUtils) |
| `npm run test:server` | Jest server (auth, pagination, API smoke) |
| `npm test` | Cả client + server |

## Typecheck (checkJs shared modules)

```bash
npm run typecheck:client
```

Chỉ kiểm tra `client/src/js/modules/shared/**` với `checkJs: true`.

## E2E Playwright

```bash
npx playwright install chromium
npm run test:e2e
```

| Spec | Flow |
|------|------|
| `e2e/admin-flow.spec.js` | Admin login → tạo HV → tạo câu hỏi LT → xem trang kết quả |
| `e2e/student-flow.spec.js` | Student login → dashboard → mở trang thi lý thuyết |

Biến môi trường (tùy chọn): `E2E_ADMIN_EMAIL`, `E2E_ADMIN_PASSWORD`, `E2E_STUDENT_EMAIL`, `E2E_STUDENT_PASSWORD`, `E2E_BASE_URL`.
