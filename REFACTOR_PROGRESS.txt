## Phase 4 — Admin (HOÀN THÀNH + NÂNG CẤP 2026-05-26)

### Đã làm (nâng cấp)
- Tách **6 trang admin** (hub + 5 trang con) thay tab một file.
- Shell dùng chung: `adminShellView.js` + `adminPages.js`.
- **Phân trang server** `GET /api/admin/result-rows` → `{ data, total, page, limit, totalPages }`.
- Tương thích ngược: `GET /api/admin/results` không query `page`/`limit` vẫn trả mảng `data`.
- Modal Bootstrap xác nhận xóa (`confirmModalView.js`) thay `confirm()`.
- Playwright E2E admin + student (`npm run test:e2e`).
- Service Worker v5 + `npm run build:sw-manifest`.
- Học viên: nút **Đánh dấu đã xem** → `POST /api/learning/lessons/:id/watched`.
- `client/jsconfig.json` + `npm run typecheck:client` (checkJs shared).

### Lệnh kiểm thử

```bash
npm run test:client    # 16 tests (5 suites)
npm run test:server    # 13 tests (3 suites)
npm run typecheck:client
npm run build:sw-manifest
npm run test:e2e       # Playwright (cần playwright install chromium)
```

Chi tiết QA: `QA_CHECKLIST.txt`.

## API phân trang kết quả admin

`GET /api/admin/result-rows?page=1&limit=20&search=&course=&type=&status=`

| Field | Mô tả |
|-------|--------|
| `data` | Hàng trang hiện tại (đã merge LT/MP/3rd-party) |
| `total` | Tổng sau lọc |
| `page`, `limit`, `totalPages` | Meta phân trang |
